# Transformers From Scratch 🚀

A 12-day hands-on learning journey to understand Transformer architecture using Python and TensorFlow/Keras.

## 📚 Topics Covered
- Text Tokenization and Embeddings
- Positional Encoding
- Self-Attention and Multi-Head Attention
- Transformer Encoder and Decoder
- Complete Transformer Architecture
- NLP Mini-Project

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- NumPy
- Jupyter Notebook

## 📅 Progress
- [x] Day 1: Tokenization and Embeddings
- [ ] Day 2: Positional Encoding
- [ ] Day 3–12: Attention, Transformer Architecture, and Mini-Project

## 🎯 Goal
Build a strong foundation in Transformers and prepare for advanced topics such as BERT, GPT, and Large Language Models (LLMs).
